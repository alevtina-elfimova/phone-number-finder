# phone-number-finder
Программа для проверки и поиска синтаксически корректных телефонных номеров с использованием языка программирования Python.

Программа предназначена для проверки и поиска синтаксически корректных российских телефонных номеров.
Программа умеет:
- проверять правильность введенного номера
- искать номер в тексте
- искать номер в файле 
- искать номер на веб-странице по ссылке

Для поиска использовалось регулярное выражение.

Для работы программы необходима библиотека requests.
Установить ее при запуске программы можно командой pip install -r requirements.txt

При запуске программы появляется меню, в котором необходимо выбрать действие.
При проверке работы тестов выполнить команду python -m unittest discover -s tests

Тесты проверяют правильность поиска и првоерки номеров, работу с фалйми и веб-страницами, а также обработку ошибок.
